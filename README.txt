데이트백 (설치형 웹앱)

[올리는 파일] 이 폴더 안의 파일과 icons 폴더를 GitHub 저장소 맨 위(루트)에 그대로 올립니다.
  index.html / manifest.webmanifest / sw.js / exifr.umd.js / icons/ (아이콘 4개)

[수정 후 다시 올릴 때] 바뀐 파일만 덮어 올리면 됩니다.
  인터넷에 연결된 상태에서 앱을 한 번 열면 자동으로 최신 버전이 반영됩니다.

[개인정보] 사진은 기기 안에서만 처리되며 어디에도 업로드되지 않습니다.

사용 라이브러리: exifr (MIT, LICENSE-exifr.txt), JPEG 인코더 (Adobe BSD / jpeg-js BSD-3, index.html 안에 고지)
